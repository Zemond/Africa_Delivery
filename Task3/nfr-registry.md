# Реестр нефункциональных требований (НФТ)

Учтены критерии Cloud Native (CNCF): декларативная конфигурация, наблюдаемость, устойчивость, переносимость между провайдерами, автоматизация. Источники — артефакты 1, 2, 5, 6.

|---|---|---|---|---|---|---|
| NFR-01 | Доступность | Каталог доступен для покупки сквозно (вкл. CDN) | Доля успешных (2xx) ответов | 99,9% в месяц | Сквозной SLI + RUM/трейсинг | Арт. 1, 2, 5 |

## Примечание по Cloud Native

Выбранный модульный монолит не противоречит критериям Cloud Native: он пакуется в контейнеры, конфигурируется декларативно (IaC), наблюдаем и переносим между провайдерами. Отличие от «классического» cloud native — не гоняем десятки микросервисов на старте, а держим границы модулей такими, чтобы вынести их в сервисы позже без переписывания.
