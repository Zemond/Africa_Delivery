# Capability Map — Africa Delivery

Возможности платформы (что система умеет), а не список функций из артефакта 4. Иерархия L1/L2.

## Иерархия L1 → L2

- L1. Каталог и контент
  - L2. Управление товарами (SKU, атрибуты, изображения)
  - L2. Категории и таксономия
- L1. Поиск и дискавери
  - L2. Полнотекстовый поиск
  - L2. Рекомендации (простые, не ИИ)
- L1. Заказы
  - L2. Корзина и оформление
  - L2. Статусы и история заказа
- L1. Платежи и расчёты
  - L2. Приём платежей
  - L2. Выплаты продавцам
  - L2. Сверка (reconciliation)
- L1. Логистика и доставка
  - L2. Интеграция перевозчиков
  - L2. Отслеживание (track & trace)
- L1. Продавцы
  - L2. Онбординг
  - L2. Кабинет продавца
- L1. Покупатели
  - L2. Аккаунт и профиль
  - L2. Согласия (consent)
- L1. Уведомления
  - L2. SMS / push
  - L2. WhatsApp
- L1. Аналитика
  - L2. Дашборд руководства
  - L2. Операционная отчётность
- L1. Безопасность и комплаенс
  - L2. Аутентификация/авторизация
  - L2. Локализация данных
  - L2. Антифрод (базовый)
- L1. Платформа
  - L2. CI/CD и наблюдаемость
  - L2. Инфраструктура как код

## Таблица решений Build / Buy / Partner

| Capability (L1/L2) | Решение | Обоснование | Стоимость (оценка) | Риск |
|---|---|---|---|---|
| Каталог и контент | Build | Ядро маркетплейса, дифференциатор | ФОТ команды (в TCO) | Низкий |
| Поиск | Buy (OSS) | Typesense/Elasticsearch — зрелый open source, не строим поиск сами | ~$0 лицензия + хостинг | Низкий |
| Заказы | Build | Ядро сделки | ФОТ | Низкий |
| Платежи | Partner | Лицензию за 8 недель не получить (артефакт 3); комиссия < 2,5% GMV | Комиссия ~2,5% GMV | Средний (зависимость) |
| Логистика | Partner | Sendbox/Sendy; своя логистика — 6 мес и 4 инженера (артефакт 5), не успеваем | Комиссия за заказ | Средний |
| Онбординг продавцов | Partner + Build | WhatsApp Business API как канал + лёгкий внутренний кабинет | Подписка WhatsApp | Низкий |
| Кабинет продавца | Build (отложено) | MVP не требует; после запуска | ФОТ | Низкий |
| Покупатели (аккаунт, consent) | Build | Consent обязателен (POPIA), делаем сами | ФОТ | Низкий |
| Уведомления | Partner + Build | SMS-шлюз (партнёр) + внутренний диспетчер | $0,04/SMS | Низкий |
| Аналитика | Buy (OSS) | Metabase/Grafana поверх своей БД, не строим BI с нуля | ~$0–сотни $/мес | Низкий |
| Безопасность/комплаенс | Buy/Partner | KMS у провайдера, WAF как сервис | В TCO (блок 2) | Низкий |
| Платформа (CI/CD, IaC) | Build | Terraform + GitHub Actions, стандарт | ФОТ | Низкий |

## Критерий отбора

Решение «build» только для ядра сделки (каталог, заказы, аккаунт, уведомления) и только если это не требует лицензий и не выходит за бюджет/команду. Всё, что не является нашим дифференциатором, — покупаем или партнёрим. Собственная логистика и платёжная оркестрация (позиция CTO) отклонены расчётом из Задания 2: они не окупаются на старте.
